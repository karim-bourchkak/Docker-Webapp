# Dockerized Flask Web Application

A lightweight Python Flask web application containerized using Docker, developed as part of the *Fachinformatiker* portfolio.

---

## 🚀 Features
* **Python Flask**: A micro web framework for building the application backend and routes.
* **Dockerized**: Fully containerized with a dedicated `Dockerfile` for consistent deployment across any environment.
* **Dependency Management**: Uses `pip` and `requirements.txt` to handle libraries seamlessly.
